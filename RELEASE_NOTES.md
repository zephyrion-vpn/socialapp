# SocialApp 1.0.0

Первый публичный релиз: production backend для Railway и устанавливаемый Windows-клиент.

## Артефакты

| Файл | Назначение |
| --- | --- |
| `SocialApp-Setup-1.0.0.exe` | Установщик Windows (NSIS): ярлык на рабочем столе, пункт в меню «Пуск», корректное удаление |
| `SocialApp-Portable-1.0.0.exe` | Portable-версия, запуск без установки |
| `latest.yml` | Манифест для авто-обновления (electron-updater) |
| `socialapp-server-1.0.0.tar.gz` | Собранный backend (dist + Prisma schema + миграции) |

## С чего начать

1. Разверните backend на Railway — [`docs/RAILWAY.md`](docs/RAILWAY.md).
2. Скачайте и установите `SocialApp-Setup-1.0.0.exe`.
3. Запустите приложение из меню «Пуск».
4. Укажите адрес сервера (экран входа → `Server: …`, либо Settings → Server), если он отличается от вшитого по умолчанию.
5. Зарегистрируйтесь и пользуйтесь.

## Возможности

* Лента с четырьмя стратегиями (подписки, рекомендации, популярное, свежее) и cursor pagination.
* Посты, ответы (threads), репосты, цитаты, лайки, закладки, хэштеги, упоминания.
* Профили с аватаром, баннером и четырьмя вкладками; подписки, блокировки, mute.
* Уведомления (в том числе нативные Windows-уведомления и badge), поиск, тренды, закладки.
* Загрузка изображений в S3-совместимое object storage.
* Тёмная/светлая тема, плотность интерфейса, горячие клавиши, skeleton-загрузки, offline-режим.
* Шифрованное хранение сессии через Windows DPAPI (`safeStorage`).

## Заметки

* Сборка не подписана code-signing сертификатом, поэтому SmartScreen при первом запуске может показать предупреждение («Подробнее» → «Всё равно запустить»). См. `docs/RELEASE.md`.
* Desktop-приложение не запускает локальный backend и не содержит серверных секретов.
